# Creaciones Kathy · App de reportes de taller

**App publicada:** https://kyonoxc.github.io/creaciones-kathy/ (se instala desde ahí en computadora, tablet o celular).

Fichas de medidas, cálculo de tela y reportes de una hoja carta para imprimir. Pide iniciar sesión; las fichas se guardan en la nube y funcionan sin internet.

## Desarrollo

Necesitas Node.js 18 o más nuevo.

```
npm install      # solo la primera vez
npm run dev      # http://localhost:5173
npm test         # pruebas
npm run build    # versión final en dist/
```

Cada cambio que se sube a `main` se publica solo en GitHub Pages.
